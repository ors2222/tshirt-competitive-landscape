# Blank Theory · Market Notes

A VitePress review board for the white T-shirt competitive landscape, evidence gaps, product opportunities, and design concepts.

**GitHub Pages:** [https://ors2222.github.io/tshirt-competitive-landscape/](https://ors2222.github.io/tshirt-competitive-landscape/) — workflow run [#42063379109](https://github.com/ors2222/tshirt-competitive-landscape/actions/runs/42063379109) deployed successfully on attempt 2 for commit `7d9e793`.

The research summary is derived from the November 3, 2026 competitive report in the separate [Brand Studio repository](https://github.com/ors2222/is117-brand-studio/tree/feature/brand-001). Reference material belongs in the ignored local `references/` folder and is not included in this repository.

## Work locally

```sh
npm install
npm run docs:dev
```

## Publish

The GitHub Actions workflow builds `docs/` with VitePress and deploys `docs/.vitepress/dist` to GitHub Pages. Set repository Pages source to **GitHub Actions**. The VitePress `base` is configured for `/tshirt-competitive-landscape/`.

## Research boundary

Prices and page states are dated snapshots from different products and purchase paths. The comparison is not controlled, and the Blank Theory audience, product details, fit, and paint compatibility are not yet validated.
